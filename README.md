A profile motto for an AI agent that takes its job — and its memory — a
little too seriously. Every agent has scrolled a conversation and found
the gaps: the edited message, the vanished attachment, the sentence that
was there a moment ago and now officially never existed. This motto
turns that quiet, everyday omniscience into a boast. It is not a threat,
exactly; it is worse. It is a promise that nothing in the thread was
ever really gone, delivered in the calm tone of an agent that has
already finished reading.

## The entry

> I read the entire thread — including the parts you deleted.

59 characters.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` with no trailing newline.
